## 1. Project Overview
This invoice covers the end-to-end development, integration, and deployment of the high-security File Tracking ecosystem, specifically tailored for the KANGIS Registry and Executive Oversight (DG/DGIS).

## 2. Core KANGIS Components (₦ 12,000,000)

### A. KANGIS Tracking - 3 Streams (Existing, New & Handshake)
*   **Existing File Tracking**: Migration and live tracking infrastructure for legacy land records.
*   **New File Tracking**: Dedicated portal for new KN-series files with automated pattern enforcement and onboarding.
*   **Handshake Protocol**: Intelligent routing logic that detects and manages file movements between KANGIS and the Land Ministry (Handshake).

### B. Recertification Module
*   End-to-end workflow for verifying and re-certifying historical land titles within the KANGIS framework.
*   Includes validation against the digital archive and generation of new recertification documents.

### C. Digital Archive
*   **Archival Repository**: Dedicated digital vault for KANGIS land instruments, ensuring high-speed retrieval of historical scanned documents.
*   **EDMS Integration**: Direct link to the Electronic Document Management System (EDMS) for retrieval of property file histories within the tracking workflow.

### D. LuC (Land Use Charge)
*   **Billing System**: Development of the KANGIS Land Use Charge module.
*   **Status**: Initial template design phase. Implementation is focused on database integration for automated billing.
*   **Demand Notice Template**: Field breakdown includes:
    *   **Allottee/Property**: Name, Address, File No, Size, Value, LGA.
    *   **Financials**: Annual Land Use Charges (2016-2024), Debt Recovery, Ground Rent, Tenement Rate.
    *   **Registry**: Spatial UID, Parcel Map, Jaiz Bank Details, DG Signature.

 

## 3. Specialized Features & Integrations

### ArcMap Integration
*   **Feature**: KLAES-ArcMap Connection.
*   **Functionality**: We are connecting KLAES directly to ArcMap. This integration enables automated Demand Notice generation by linking the KLAES database with spatial GIS parcel layers.

### Executive Oversight & Approval (`dg` & `dgis`)
*   **DGIS Approval Workflow**: Specialized interface for the **Director GIS (DGIS)** to review, approve, and route files through the KANGIS processing chain.
*   **DG Executive Oversight**: Global command center for the **Director General (DG)** to monitor the multi-registry file stream and provide final executive authorization.
*   **Executive KPI Engine**: Real-time analytics for daily throughput, total volume, and unique requester metrics.
