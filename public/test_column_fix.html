Database Table Structure

Based on the PageTyping model, the pagetypings table has:

  • ✅ page_type - Direct storage of page type value
  • ✅ page_subtype - Direct storage of page subtype value
  • ✅ cover_type_id - Foreign key to cover_types table

The relationships work as:

  • pageType() - Maps page_type field to id in page_types table
  • pageSubType() - Maps page_subtype field to id in page_subtypes table
  • coverType() - Maps cover_type_id field to Id in cover_types table
